# Smart Helpdesk Ticket Classifier

A web-based helpdesk application built using Python, Flask, spaCy, and SQLite.

## Features

- Submit technical issues
- NLP-based issue classification
- Suggested troubleshooting steps
- Ticket history
- Clean and colorful interface

## Technologies Used

- Python
- Flask
- spaCy
- SQLite
- HTML
- CSS

## Project Workflow

1. User enters issue
2. NLP analyzes text
3. System classifies issue
4. Ticket is stored in database
5. Suggested solution is displayed

## Run Locally

pip install -r requirements.txt

python app.py
